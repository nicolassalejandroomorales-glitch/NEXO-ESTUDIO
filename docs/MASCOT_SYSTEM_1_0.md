# Mascota y cosméticos

La mascota es un estado global (`state.mascot`), no cuatro copias por pantalla. `dist/mascot/controller.js` recibe especie, equipamiento, habitación, actividad y evento ambiental, y devuelve una intención de dibujo. Las especies actuales del catálogo son cerdito, gato y perro; `avatar/catalog.js` conserva su inventario y normaliza cambios de especie. `avatar/contracts.js` define ranuras `head`, `face`, `shirt`, `back`, `tail`, `aura`, `background`, y reserva `main_hand`/`off_hand` para objetos futuros. La compatibilidad se comprueba por especie, ranura y habitación.

El personaje visible combina base y piezas de `avatar/vector-art.js`; la tienda muestra el objeto solo en la cuadrícula y la previsualización compuesta al elegirlo. No se deben añadir nuevos cosméticos como una imagen plana superpuesta sin probar las anclas de cada especie. Para agregar una especie: base visual, metadatos y precio del catálogo, anclas/compatibilidad, fallback y pruebas de las ranuras. Para añadir un cosmético: identificador estable, ranura, recorte, precio, compatibilidad y prueba visual en las tres especies.

`rive/mascots/scene.rml` y `mascot-rive.js` son la base para animación; el rig actual no proporciona anclas finales ni un conjunto completo de estados como leer, escribir, combatir o dormir. No se fingen esas animaciones mediante un overlay frágil: Canvas conserva los cosméticos cuando Rive no puede hacerlo. Antes de reemplazar el fallback, preparar un rig real con anclas semánticas y estados y comparar imágenes de cada combinación. `ambient/events.js` elige eventos deterministas por hora/bloque sin mantener timers por mascota.

El primer prototipo reemplazable está en `rive/companion-v2/`: un cerdito nuevo con imágenes completas e integradas para reposo, lectura con lentes/libro y entrenamiento con báculo. Sus tres animaciones se compilan a `nexo-companion-v2.riv` y el runtime elige una según la habitación. La mascota también permanece en la navegación lateral (o la barra superior en móvil) fuera de Inicio; el renderer pausa Rive cuando el lienzo no es visible o la pestaña se oculta. Esto **no** equivale aún a un rig articulado: faltan huesos/meshes, expresiones faciales independientes, anclas para cosméticos y los estados de gato y perro. Si hay piezas equipadas, se usa la composición Canvas para no perderlas.

Las pruebas de `tools/avatar-test.cjs` y `mascot-controller-test.cjs` verifican inventario, compatibilidad y fallback. Falta una inspección visual exhaustiva de todas las combinaciones en dispositivo real.
