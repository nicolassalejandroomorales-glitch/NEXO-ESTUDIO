# NEXO — UPDATE 01.3
## ROOM INTERACTIVITY FOUNDATION + GRIMOIRE INTRO POLISH

Trabaja sobre la versión actual posterior a UPDATE 01.2.

NO volver a la base antigua.
NO rehacer desde cero Inicio ni Aprender.
NO implementar todavía el sistema completo de clases funcionales.
NO implementar todavía la tienda ni la personalización completa.
NO implementar todavía el sistema final de mascota.

Objetivo de esta fase:
1. convertir Inicio en una habitación más estructurada e interactuable;
2. preparar la escena para futura personalización y uso por la mascota;
3. enriquecer la zona inferior para que no se vea vacía;
4. mejorar la apertura del grimorio para que se sienta más mágica y ceremonial;
5. mantener el producto usable y estable.

==================================================
1. CONTEXTO
==================================================

La base visual actual ya es buena y útil.
No quiero perderla.

Ahora necesito una mejora estructural en dos áreas:

A. INICIO como habitación-sistema
B. APRENDER como grimorio con mejor introducción

Esta fase es de integración y polish estructural,
no de rediseño total.

==================================================
2. PROBLEMAS ACTUALES A RESOLVER
==================================================

P1. Inicio mejoró, pero todavía quiero que la habitación superior
sea más claramente una escena habitable e interactuable.

P2. El fondo ya no debe entenderse sólo como imagen decorativa,
sino como una escena que en el futuro pueda albergar acciones,
objetos y personalización.

P3. La parte inferior todavía se siente algo vacía;
quiero más continuidad material (madera, verde, enredaderas).

P4. Quiero que ciertos elementos del escenario empiecen a existir
como objetos del mundo:
- biblioteca
- ventana
- escritorio
- zonas de descanso
- zonas decorativas

P5. La apertura del grimorio me gusta,
pero la animación inicial de la portada aún debe sentirse
más mágica, más suave, más rica y más ceremonial.

P6. Las transiciones internas entre páginas/ramos
deben seguir siendo más rápidas que la introducción.

==================================================
3. OBJETIVO — INICIO COMO HABITACIÓN-SISTEMA
==================================================

Inicio debe evolucionar desde “pantalla bonita”
hacia “habitación viva preparada para interacción”.

No quiero solo una ilustración.

Quiero una escena estructurada con:

- ventana clara e importante;
- biblioteca/estantería;
- escritorio;
- zona de mascota;
- materiales cálidos;
- vegetación;
- piso / base visual inferior;
- continuidad hacia la zona funcional.

Debe sentirse como un lugar real dentro del mundo de Nexo.

==================================================
4. INTERACTABLES DE ESCENA
==================================================

NO implementar todavía toda la lógica final de gameplay.

Sí quiero dejar la base para que ciertos elementos existan
como entidades del escenario.

Objetos principales a preparar:

- bookshelf / biblioteca
- window / ventana
- desk / escritorio
- rest-area / zona descanso
- decor-slots / slots decorativos

Cada uno debe poder tener como mínimo, si la arquitectura lo permite:

- id
- tipo
- bounds o zona
- capa/profundidad
- estado visual básico
- acción o destino conceptual
- metadata futura

Ejemplo:
bookshelf
→ abrir biblioteca
→ sacar libro / poner libro (futuro)

window
→ foco de iluminación
→ comportamiento de día/noche

desk
→ continuar estudio / zona mascota

NO implementar todavía todas esas acciones finales.
Solo preparar la estructura para que la habitación no tenga
que reconstruirse luego.

==================================================
6. ESCENA SUPERIOR + PARTE INFERIOR
==================================================

Quiero mejorar la continuidad visual de la parte inferior.

Problema actual:
la parte de abajo se siente vacía.

Resultado deseado:
- más sensación de piso / madera inferior;
- continuidad de materiales cálidos;
- enredaderas o vegetación descendiendo más abajo;
- integración visual entre escena superior e interfaz inferior;
- seguir manteniendo claridad y legibilidad.

No llenar por llenar.
Debe sentirse bonito, orgánico y coherente.

==================================================

Mantener la mascota actual.

- cambio de mascota

==================================================

La ventana debe ganar protagonismo.

- noche

Mejorar, si es razonable:

- resplandor;

- protagonismo visual de la ventana.

No rediseñar un nuevo sistema horario completo si no hace falta.
Pulir el existente.

9. GRIMORIO — INTRO CINEMÁTICA
==================================================

La apertura del grimorio debe mejorar.

Quiero que la introducción del grimorio sea:

- más lenta que ahora;
- más suave;
- más ceremonial;
- con más presencia de la portada;
- con más detalle mágico;
- con destellos/brillos sutiles;
- con sensación de magia.

Debe sentirse como la entrada a un objeto especial.

La portada debe poder verse y sentirse mejor antes de abrir.

Inspiración funcional:
un grimorio mágico muy ornamentado, poderoso,
detallado y atractivo.

NO copiar directamente ninguna obra específica.
Traducir la inspiración a propiedades visuales y de animación.
